# Tarea 1 del Modulo Optativo

Proyecto para aprender Git y GitHub. Es un sitio web básico hecho solo con HTML, al que se han añadido mejoras trabajando con ramas y Pull Requests.

## Tabla de Contenido
- [Instalación](#instalación)
- [Estructura](#estructura)
- [Mejoras implementadas](#mejoras-implementadas)

## Instalación
Para ver el proyecto, clona el repositorio y abre `index.html` en el navegador:

`git clone https://github.com/isabelmarpolo9/Tarea1-modulo-optativo.git`

## Estructura
- `index.html`: página principal del sitio.
- `.gitignore`: archivos y carpetas excluidos del repositorio.
- `README.md`: documentación del proyecto.

## Mejoras implementadas
- Menú de navegación con enlaces internos (rama `feature/menu`).
- Footer con enlaces a redes sociales (rama `feature/footer`).
